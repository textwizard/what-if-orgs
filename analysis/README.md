# analysis

The scripts that produce the results and figures reported in the proposal, the appendix, and the artifact. Run from the repository root with `PYTHONPATH=.`.

| Script | Produces |
|---|---|
| `inputs.py` | The inputs of the reference organizations from the archived websites: NACE division, firm profiles, situation of the firm, theory of value |
| `diagnostics.py` | Ranking per condition, mean probability by product attribute, firm-level agreement, and the regression on the product record |
| `anchor_contrast.py` | The agents with the web anchors, without them, and without the anchors of each theory's own constructs |
| `hot_stove.py` | The three readings of the own-history run: persistence, hardening, timing |
| `figure_strategy.py` | Figure 2 of the proposal, the empirical strategy |
| `figure_architecture.py` | Figure 1 of the artifact, the architecture of the instrument |
