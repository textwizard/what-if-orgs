# protocols

The coding protocols given to the language model, one per coding, as sent. Every coding keeps a verbatim quote from the page it rests on.

| Protocol | Coding |
|---|---|
| `year.md` | Products and statements per firm-year |
| `firm.md` | Stated strategy and characteristics of the firm |
| `context.md` | Situation of the firm in the context year |
| `value.md` | Theory of value, 100 points over four emphases |
| `division.md` | NACE division of the firm from its website |
| `relatedness.md` | Relatedness of each new product to the established offer |
| `aliases.md` | Names that refer to the same product |
| `anchors.md` | The anchors of each theory's constructs, removed in the own-anchor condition |
