# Data licence

The list of pilot firms in `data/public/pilot_firms.csv` is released under the Creative Commons Attribution 4.0 International licence (CC BY 4.0, https://creativecommons.org/licenses/by/4.0/). It is the only data file in the repository.

The sample frame, the sampling variables, and all data derived in the project stay with the authors, since they build on proprietary company data. Eurostat tables are downloaded from the Eurostat API by the code and are subject to the Eurostat reuse policy, and website text is retrieved from the Common Crawl archive under its terms of use.
